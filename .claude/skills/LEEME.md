Esta carpeta es el punto de montaje del submódulo `minos-skills`.

En el ZIP de entrega viene vacía a propósito: el catálogo se monta con

    git submodule add https://github.com/<ORG>/minos-skills.git .claude/skills

Ver docs/03-adopcion-coder.md, paso 2. El catálogo va en el ZIP como carpeta
hermana `minos-skills/` para que puedas publicar ambos repos.
